On the data engineering side, I architected a SQL Data Warehouse utilizing a Star Schema with 4 fact tables and 7 dimension tables, supported by an automated Python ETL pipeline that handles data cleaning, deduplication, and schema validation.

On the analytics and modeling side, I authored over 50 advanced SQL queries leveraging window functions and CTEs to build cohort retention matrices and stickiness metrics.
